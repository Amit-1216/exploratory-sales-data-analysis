# Exploratory Sales Data Analysis

## Overview
An exploratory data analysis project using Python and Pandas to analyze
customer shopping behavior and sales trends.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Key Insights
- Spending trends vary significantly across age groups
- Subscription-based customers show higher purchase value
- Seasonal and promotional factors impact sales performance

## How to Run
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Open the notebook and run all cells
